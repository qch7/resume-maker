# 隐私保护

隐私保护默认强制开启，所有生产 AI 功能共用 `CodexProvider` 的文字脱敏出口。真实资料仍保存在本机，模型接收替换后的上下文；返回结果在本机还原后继续进行字段、模板引文和源码证据校验。

## 发送边界

| 入口 | 外发材料 | 本机保留 |
| --- | --- | --- |
| 项目分析和聊天 | 脱敏后的当前经历、项目资料、最近 16 条本机消息、有界源码文字 | 原始项目、绝对目录、数据库和历史供应商会话 |
| 模板识别及修复 | 脱敏后的节点原文、字段需求、布局结构和校验反馈 | 原始 DOCX/PDF、照片、原始整页图和试填资料 |
| 荣誉识别 | 可提取的 PDF 文字及文件名，经过同一脱敏出口 | 证书原件和页面图片；没有文字的图片或扫描件转人工录入 |
| 连接测试 | 固定测试提示词，经过同一出口 | API 凭据仅用于供应商鉴权 |
| 保存、预览和导出 | 不调用模型 | 使用真实资料在本机处理 |

没有本地 OCR 的当前版本不尝试凭空判断图片是否安全，原始图片和扫描件在模型出口明确拦截。可编辑模板继续依据文字和 OOXML 布局识别，照片映射及复杂版式需人工核对。原有视觉恢复函数不能绕过出口发送原图。

## 本地处理

- 每轮读取本实例已保存的个人信息、教育院校字段、荣誉获奖人、颁发单位、证书编号及用户补充的敏感词。模板任务额外登记本轮尚未保存的资料，隐藏字段同样受保护。
- 格式规则识别常见邮箱、手机号、身份证号、长卡号、网址、IP、用户目录、明确标注的姓名及地址；已知敏感值同时处理 JSON Unicode 转义和 URL 编码。
- 相同值使用同一轮的随机占位符，不同请求重新生成。映射只保存在请求内存，不写入供应商请求、磁盘文件或审计。跨行替换保留换行，以便引用原始源码行号。
- 凭据赋值、已识别密钥及私钥内容直接移除，不能通过还原重新进入结果。编码附件及过长编码文本直接拦截。
- 模型回复中的占位符在本机单次还原，未知或损坏的占位符拒绝采用。格式失败的反馈下轮重新脱敏，不直接重发真实资料。

项目源码在本机收集，跳过链接、凭据、二进制、常见数据和依赖目录。单轮最多读取 200 个文件，每文件最多 128000 字节，正文总计 350000 字符，最多检查 10000 个文件名和 10000 个目录；不足或遗漏范围明确提供给模型。这个范围会影响大项目分析覆盖率，可以关联更小的子项目目录。

## 连接和历史

生产请求直接使用 Responses API，发送 `tools=[]`、`tool_choice=none` 和 `store=false`。不运行 CLI 模型进程，不加载 CLI 插件、技能、记忆、工具或历史会话；模型返回工具请求时直接拒绝。每轮从本机历史重建上下文，旧 `provider_thread_id` 不外发。原始文件、还原表及本机工作目录不会作为附件发送。

连接只读取 `CODEX_HOME/config.toml`（缺省为用户 `.codex`）、选中的配置档及 API 鉴权字段：支持 `model`、`model_reasoning_effort`、`model_provider`、`model_providers.*.base_url`、`wire_api=responses`、`env_key`、`experimental_bearer_token`，以及 `auth.json` 中的 `OPENAI_API_KEY`。配置档支持 `profiles.<name>` 和 `<name>.config.toml`。模型设置可覆盖配置中的模型名和推理强度，未覆盖时沿用所选配置。

仅 ChatGPT/Codex 订阅登录、依赖 CLI 插件或其他协议的连接不适用，明确报错且不自动回退旧通道。远程地址必须使用 HTTPS，本机地址允许 HTTP；不跟随重定向，不自动重试，不把供应商错误正文放入应用日志。取消会关闭等待中的 HTTP 请求，不能撤回供应商已经收到的数据。

`store=false` 只是发给供应商的协议参数，不能保证第三方不留存，也不改变其数据政策。

## 检查和使用

工作台设置中的“隐私保护”支持补充准确敏感值、在本机检测文字、查看和清除最近 10 条请求。检测只处理输入的那段文字；发送记录显示实际发出的完整请求体，包含模型、脱敏上下文和输出格式。`prepared` 表示已准备发送，不能据此断言供应商已收到；失败和取消也不能证明供应商没有收到。

审计不包含鉴权头、模型响应或还原表，但可能包含业务材料及检测遗漏的内容；它随本机数据库及 ZIP 备份保存。保留最近 10 条是有界存储，不是加密或匿名化承诺。清除记录不会撤回已发请求。

## 能力边界

自动规则无法识别所有未知姓名、无标签身份、任意编码、商业秘密或根据经历推断身份的线索。对学校、单位、地点、个人网址等额外敏感内容，应补充准确词条并检查本地检测及发送记录。未保存、也未随当前任务提供的其他浏览器表单不会被读取为敏感词。

本改造不提供本机静态加密，不防御已经控制本机的程序，不清除旧版 CLI 会话或撤回旧请求。原件、真实简历、聊天记录及备份仍需按本机资料管理。脱敏降低已知个人信息外发风险，不能承诺全部内容不可识别。

## 验证

自动测试使用合成资料、临时配置、临时数据库和 HTTP MockTransport，检查真正的请求体、引文还原、未知占位符、图片及工具拦截、取消、重定向和错误反馈。测试夹具禁止真实 HTTP 传输并隔离用户 CLI 配置。规则测试通过不代表未知材料已经被完整匿名化。
