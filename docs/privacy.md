# 隐私保护

所有生产 AI 功能经过同一脱敏网关。原始资料留在本机，模型获得脱敏文字和布局信息；模板内嵌图片、图片模板及 PDF 扫描页在本机打码、重新编码后作为受控附件提供。结果在本机还原后继续核验字段、模板引文和源码证据。当前实现保留 Windows 原生 Codex CLI，不需要 WSL、Docker、Windows Sandbox 或 GPU。

## 数据流

```mermaid
flowchart LR
  A[本机原件和资料] --> B[文字提取或本地 OCR]
  B --> C[登记敏感值和替换占位符]
  C --> D[单次脱敏副本]
  D --> E[只读材料工具]
  E --> F[原生 Codex CLI]
  F --> G[模型供应商]
  G --> H[本机还原和引用校验]
```

| 入口 | 模型可见内容 | 本机保留 |
| --- | --- | --- |
| 项目分析和会话 | 脱敏经历、资料、最近 16 条消息和按需返回的源码片段 | 原始源码目录、数据库、旧供应商会话 |
| 模板识别和修复 | 脱敏节点文字、字段需求、位置、校验反馈和带节点编号的马赛克图片拼图 | DOCX/PDF/图片原件、照片原件、整页截图、试填资料 |
| 图片模板和扫描 PDF 版面恢复 | 脱敏重绘的整页图、OCR 占位文字及原始比例坐标 | 原始页面、OCR 原文、身份还原表、照片原件 |
| 荣誉识别 | 本地提取并脱敏的证书文字和坐标 | 原始证书及页面像素 |
| 保存、预览和导出 | 不调用模型 | 使用真实资料本机处理 |

## Windows 工具沙箱

这里的 sandbox 是**受限工具和脱敏副本组成的应用层边界**，没有宣称为 AppContainer 或虚拟机。受信任的应用后端和 CLI 控制进程仍以当前 Windows 账户运行。模型不能任意运行 PowerShell，也没有本机通用文件读取入口。

- 每轮在系统盘 `ResumeMakerSandbox/task-*` 建立独立目录。父目录及任务文件 ACL 只允许当前账户、管理员和 SYSTEM；任务结束清理。脱敏材料和控制文件分开保存。
- POSIX 使用 `/tmp/resume-maker-sandbox`，创建任务前核对父目录属于当前账户且权限为 `0700`，拒绝链接、其他账户目录和过宽权限。
- CLI 使用新的 `CODEX_HOME`、`--ephemeral`、`--ignore-user-config`、`--ignore-rules` 和严格配置，不续用供应商会话。仅复制 `auth.json`；不复制旧历史、技能、插件和项目规则。
- `CODEX_HOME` 使用 `control/codex-home`，`TEMP/TMP/TMPDIR` 使用同级的 `control/tmp`，避免 CLI 因配置目录位于临时文件目录内而拒绝创建 PATH 辅助程序；两者都留在本轮任务目录并随任务清理。保留 `skip_host_skill_discovery`，通过 `suppress_unstable_features_warning` 关闭开发功能启动提示，其他诊断继续写入日志。
- 每轮生成受控模型目录，保留用户选定的模型名称，固定标准 Responses 工具协议、禁用 shell、补丁和代码编排。CLI 内置模型元数据可能重新启用这些能力，仅关闭功能开关不足以保证工具集合。
- 禁用 shell、补丁、浏览器、计算机操作、图片读取工具、图片生成、网络搜索、代理、记忆和外部 MCP。模板马赛克图片由隐私出口作为受控附件提供，仅有附件时开启模型图片输入能力。只注册内置 `resume_materials` 服务：`read_material` 和 `search_materials` 读取初始材料，源码任务另提供 `list_source_files`、`search_sources` 和 `read_source`。CLI 保留自身的 MCP 资源调度和交互工具，本服务不提供资源、写入、任意网络或执行接口。
- 静态材料只接受 `context.txt` 和 `source-0001.txt` 这类生成编号。源码工具接受本轮来源编号和相对路径，经受信任后端核验范围后返回脱敏结果；绝对路径、`..`、Windows ADS、链接、硬链接、凭据和应用自身数据目录被拒绝。读取最多 200 行，单次结果最多约 24000 字符，列表和搜索每页最多 100 条，可继续访问。
- 每轮提示明确列出实际启用的材料工具，要求直接读取脱敏材料；模型指令禁止调用 CLI 内置的 `list_mcp_resources`、`list_mcp_resource_templates` 和 `read_mcp_resource`。这些工具仍可能出现在 CLI 工具目录中，事件检查继续拒绝它们，提示词不替代权限边界。
- 原始目录和还原表仅由后端持有。独立材料进程通过随机端口和随机凭据连接 `127.0.0.1` 上的本轮网关；凭据位于工具不可读的控制目录，不放入模型上下文。网关拒绝带 Origin 或鉴权不符的调用，不继承网络代理；退出即停止读取并清理缓存和游标。
- 目前固定验证 Codex CLI **0.154.0**。其他版本停止调用，需要先重新验证工具集合再升级支持范围；工具服务启动失败也不会切换到普通 shell。
- Windows 以挂起状态创建 CLI，加入 Job Object 后才恢复执行，避免快速退出及后代提前创建的竞态；取消和超时不发布迟到结果。不能撤回供应商已经收到的数据。

这能约束模型通过已注册工具访问资料，不能防御已被篡改的 CLI、本机恶意程序或操作系统漏洞。此前测试中 CLI 原生 Windows 沙箱对部分公共读取目录未能阻断，因此本实现不以它作为原件隔离保证。

## 脱敏规则

每轮登记本实例的个人信息、教育院校、荣誉获奖人、颁发单位、证书编号和补充敏感词，模板任务同时登记尚未保存的当前资料。隐藏字段同样处理。

结构化字段按含义登记：`personal.name` 是姓名，荣誉、项目和工具等对象的通用 `name` 不作为人名；明确的 `full_name`、`person_name`、`recipient` 等身份字段继续保护。教育经历只登记学校 `title`，专业 `subtitle` 保留；个人资料中的求职意向、GPA 和标明专业、学历、技能、成绩等业务用途的自定义信息也保留。未知标签或无标签的个人自定义值仍按敏感信息处理。普通文本的 `Name:` 支持独立行或标点分隔的标签，`filename`、`project_name`、`Project name` 等业务标签不会因名称后缀被误判。

例如，荣誉库已有“大学英语四级”时，再识别“全国大学英语四级考试”会保留完整考试名称，姓名和报告单编号仍替换为占位符。模型依据保留下来的文字提取证书名称，身份占位符在本机还原。上述业务字段仍受显式敏感词、联系方式及编号格式规则约束，低置信度 OCR 片段也继续整体遮盖。

规则识别常见邮箱、电话、身份证号、长卡号、网址、IP、用户目录，以及明确标注的姓名和地址。已知值同时处理 JSON Unicode 转义和 URL 编码。同轮相同值共用随机占位符，跨轮重新生成；映射只在内存保存，跨行替换保留换行。凭据和私钥直接移除，不可还原。编码附件及过长编码文本拒绝发送。未知或损坏的返回占位符拒绝采用。

证书标签支持学校、颁发单位及中英文姓名、证书编号，值可以位于标签下一行。识别全角字符和不可见格式符；已登记身份额外匹配 OCR 插入的空白，同时保留原始片段用于本地还原。源码副本写入时不再次转换换行，保持 Windows CRLF、LF 和 CR 的原始行号。

编号按完整范围替换：连续 12 位及以上数字、符合分组特征的长数字、四组或更多的四字符字母数字校验串，以及准考证号、报告单编号、学号、验证码等明确标签或结构字段。覆盖全角、不可见控制符、空格、连字符、斜线和数字分组换行；已识别的 OCR 分块同步登记。短数字敏感词只匹配独立值，多个命中范围重叠时合并，避免只遮盖编号中间的少量数字。成绩、普通年月日、年份列表、坐标数值和程序变量中的短数字保持原样；已明确登记为敏感值的独立数字仍会遮盖。无法确定的短编号和任意编码仍需补充规则。

纯数字文字输入也执行脱敏，不能因其可解析成 JSON 数字而绕过规则。已经由本轮生成的占位符再次处理时保持不变，未知占位符拒绝采用。替换次数包含同一信息在文字和 OCR 分块中的重复出现，不能用次数判断资料是否已完全脱敏。

程序生成的输出契约保留 JSON Schema 关键字、类型、引用和固定字段名，只对说明及动态候选值脱敏。敏感词或源码中的 `password: str` 等声明不能改坏协议类型；私人栏目名称等候选仍在发送前替换并在返回后还原。

源码清单的 `source_materials`、`files`、`text` 等固定路由字段同样保留，避免同名敏感词使只读工具找不到副本。路径、正文和未知字典键继续脱敏，不扩大工具读取范围。

源码恢复原有按需访问方式：启动前不遍历整库，不设置文件数量、单文件大小、总字符量或遍历总数预算。所有关联来源均可列出、搜索和读取；普通项目的 `data` 目录、文本锁文件和 SVG 可访问，实际应用数据目录、依赖目录、凭据、二进制及链接继续排除。引用还原后仍对照原文件核验。

列表和搜索以请求内游标继续，每页最多推进 1000 个目录、文件或行步骤；`complete=false` 时即使结果为空也要继续。正文通过 `next` 的行列坐标续读，行号对应原件，列号对应脱敏文字。分页只限制单次工作和返回量，不永久省略后续内容；多来源交替遍历。被请求的单个文件会先完整脱敏再缓存到本轮临时目录，因此超大文件仍受机器内存、处理时间和任务超时影响；这些资源限制不等于固定的源码采集预算。

## 本地 OCR 和开销

图片模板和 PDF 扫描页通过 `PageImage` 使用独立的整页通道：先本地 OCR，登记完整文字、低置信度片段、已保存身份和敏感词；每页首个通用栏目标题之前、最多上方四分之一的身份区整体保护。敏感行在图上用不透明色块和固定行号覆盖，不对文字采用可辨认的模糊。所有 OCR 文字像素先移除，再按原坐标重绘安全文字，不把原始文字裁图贴回。

非文字区域按本地连通色块合并后统一降成最长边最多八格、至少四倍缩小的马赛克，照片、图标和复杂装饰均处理，避免只依赖人脸检测。附件是全新 RGB PNG，最长边 1600 像素，不复制元数据。区域划分或 OCR 可能失误，复杂图形和字体会损失细节，因此不能承诺完全匿名或逐像素复刻。未知身份仍需补充敏感词。

模型同时获得脱敏 OCR 行、字符数和原始坐标，返回结果必须逐行保留文字、占位符及坐标；遗漏、改写或猜测被拒绝，最多重试一次。还原表只留在当前请求内存，结果通过几何和文字检查后，本地从原件裁剪照片及图标、重画标题底块并生成 Word。后续模板映射继承本页发现的身份和凭据集合；重开或修复图片来源的 Word 模板时，也从本机来源坐标重新登记身份区，缺少坐标的文字整体保护。扫描 PDF 按分节保留每页来源、纸张尺寸和已保护的段落标记，重开后继续保护各页身份区和低置信度文字。整页处理失败时不发送附件，也不会回退原图或开放图片读取工具。该通道用于独立图片模板及 PDF 中缺少可靠文字层或转换失败的页面；扫描 Word 和荣誉图片保持原 OCR 入口。

模板识别和修复额外接收已解析出的内嵌图片。隐私出口将每张图片整图缩为最长边八个色块（小图也至少按四倍缩小），再以最近邻放大；在全新的 RGB 画布上绘制清晰的节点编号，重新编码为 PNG，不复制 EXIF、ICC、文字块或原始附件。每组六张、最多二十四张，单图最多 20 MB、两千万像素。解码或打码失败时停止发送，不能回退原图；未提取及超额图片明确提示人工核对。整页原图不随模板请求发送，正文继续单独脱敏。荣誉等其他图片入口仍只使用本地 OCR。

马赛克只保留粗略颜色和轮廓，供模型结合布局判断图片用途，不提供身份识别或细节恢复。仍无法区分照片、图标和装饰时需人工确认；马赛克不保证匿名，也不保证所有图片都能识别。审计记录图片节点、色块规格、尺寸及处理后 PNG 的 SHA-256，不保存原图或图片编码。CLI 附件只写入本轮隔离控制目录，任务结束清理，普通材料工具不能读取该目录。

使用 **RapidOCR 1.4.4 + PP-OCRv4 移动版 ONNX + ONNX Runtime CPU**，模型随 Python 依赖安装，识别时不联网下载。模型延迟加载、单份复用、串行推理，设置 2 个计算线程和 1 个算子间线程。

1. 可靠 PDF 文字层直接提取。扫描页和含较大图像的混合页本地 OCR，文字层和 OCR 按位置去重。
2. 默认检测输入长边 960 像素。结果稀疏、字号过小或置信度低于 0.85 时，最多以长边 2000 像素复核一次；不放大低分辨率原图。
3. 较高分辨率结果只在覆盖不减少、平均置信度没有明显下降时采用。置信度是复核触发信号，不能代表真实准确率。证书出口的低分片段整体遮盖后外发，结果需对照原件确认。
4. 单文件最多 20 MB、12 页、单图 4000 万像素、10 万文字和 6000 个文字块。取消在页面和推理前后检查；正在执行的单次 ONNX 推理会完成后再响应取消。

上述文件及页数限制用于证书等整体 OCR 入口。PDF 模板保留原生本地结构解析，只有扫描页或解析失败的页面进入 OCR 回退；单次回退最多 12 页、10 万文字和 6000 个文字块，在外发前累计检查，同页重试不重复计数；整页恢复每页最多 1500 行。可靠文字页不会因短文字、附带照片或总页数超过 12 而提前启动 OCR 或被其页数限制拦截。原生文字层仍在本机登记身份，OCR 不确定片段仍整体脱敏。

图片模板和扫描 PDF 通过脱敏整页辅助恢复照片和装饰；扫描 Word 仍主要恢复可编辑文字及大致位置。字体、印章、复杂装饰及 OCR 原文需人工核对。原生 Word/PDF 的本地资源保留不等于把原图交给模型。旋转 90 度、手写、艺术字和严重模糊照片仍可能识别失败，必要时先旋转、重新扫描或手工录入。基准及复现命令见 [OCR 评测](ocr-benchmark.md)。

## 登录和连接

复用 `CODEX_HOME/config.toml`、`profiles.<name>` 或 `<name>.config.toml` 中的模型、推理强度、供应商地址和鉴权字段。供应商使用 Responses 协议；自定义供应商省略 `wire_api` 时显式采用 `responses`，配置其他协议时在启动 CLI 前报错。远程地址要求 HTTPS，本机测试可使用 HTTP。自定义系统提示、工具、插件、HTTP 头及任意命令不会随配置继承。

应用设置或继承的 CLI 配置必须明确模型名称，未配置时停止调用，避免 CLI 自动选择未经约束的模型元数据。

API 环境变量或 `experimental_bearer_token` 只供 CLI 鉴权，不写入材料和审计。支持文件保存的 CLI 订阅登录；仅存在系统 keyring 中的登录不在本次兼容范围，请使用文件凭据登录。临时副本刷新令牌后，仅在原凭据未被其他 CLI 修改时保存新状态；应用内部串行复用登录，避免并发刷新。

未保存资料和 OCR 登记的凭据单独保存在任务内存中，复制任务上下文时独立继承。裸凭据再次出现在提示词或契约说明中也会移除，模型回复在本机还原身份时不会还原这些凭据。

CLI 负责最终 HTTP 协议、重试及供应商通信，应用不承诺第三方留存政策。每次从本机历史重新脱敏构建上下文，旧 `provider_thread_id` 不外发。

## 检查和限制

“工作台设置 → 隐私保护”是独立页面，集中提供敏感词和脱敏预览，自动处理范围及最近发送记录按需展开。切换设置页面保留未保存输入，预览使用已保存的敏感词。可查看和清除最近 10 份脱敏材料包。记录包括初始材料、输出契约、源码工具调用总次数及最近 20 次脱敏结果，**不是 CLI 最终 HTTP 请求的完整抓包**；审计保留数量不限制源码访问。`prepared` 只表示已准备，失败和取消也不能证明供应商未收到请求。

审计不包含鉴权、模型回复或还原表，但可能保留业务材料及规则遗漏的内容；它随本机数据库和 ZIP 备份保存，没有新增静态加密。

自动规则和 OCR 无法识别全部未知姓名、无标签身份、任意编码、商业秘密或间接身份线索。OCR 高置信度也可能漏字、误认；沙箱只能限制读取范围，不能修复脱敏漏检。需补充学校、单位、地点等敏感词并核对识别结果，不能承诺完全匿名或零泄露。旧版本已发送的数据无法撤回。
