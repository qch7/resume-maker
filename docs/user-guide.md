# 使用指南

本机项目经历工作台。读取项目源码，通过 Codex 生成带证据的经历建议，逐条编辑和保存，再勾选固定版本组合成可编辑 Word 简历。

## 默认栏目

在“栏目编排”顶部可以直接添加大栏目；“填写资料”左侧的“默认栏目设置”用于集中维护默认栏目及其信息项。左侧选择个人信息、教育、项目、荣誉或其他栏目，右侧可改名、增删字段、设置初始显隐，也可以添加默认栏目和调整归属。默认设置保存在本机数据库中，随备份保留。

保存设置会更新当前简历的字段结构，之后新建的简历和条目会沿用这些设置，但不会复制填写内容。默认信息项在填写表单中可填写和隐藏，删除统一在设置弹窗操作；已有内容时会出现二次确认，确认并保存设置后该项退出表单，原值保留并隐藏。其他已保存的简历和项目版本保持独立。

## 启动

Windows 下安装 [uv](https://docs.astral.sh/uv/getting-started/installation/)、Node.js 22 和 Codex CLI，然后双击 `start.cmd`。首次运行安装 Python 依赖并构建前端，浏览器打开 <http://127.0.0.1:8765>。

关闭启动终端可停止服务；后台运行时双击 `stop.cmd`，会取消正在运行的 Codex 任务并关闭本实例。

```powershell
# 更换端口或数据目录
.\start.cmd -Port 8768 -DataDir D:\ResumeMakerData

# 强制重建界面
.\start.cmd -Rebuild
```

服务只监听 `127.0.0.1`。待分析的项目源码不需要放进本仓库。从源码启动时，个人数据默认保存在 Resume Maker 项目根目录的 `data/`，数据库为 `data/resume.db`；模板、快照、导出和备份保存在同一目录下，均由 Git 忽略。独立安装包默认使用 `%USERPROFILE%\.resume-maker`。也可设置 `RESUME_MAKER_DATA_DIR` 或传入 `--data-dir`，命令行优先。

开发期间仅支持当前数据库结构，启动和恢复不会转换旧结构。遇到结构不受支持的提示时，请通过 `--data-dir` 指定新的独立目录；原数据目录保留。相同结构的数据可通过下文的备份恢复流程转移目录。

## 使用流程

### 荣誉证书库

顶部“荣誉证书”是独立的全宽管理板块。点击“上传证书”或拖入多个文件，每个文件生成一个荣誉条目。支持 PDF、PNG、JPG/JPEG、WebP、BMP、TIFF；单文件最多 20 MB，PDF 最多 12 页；不同证书请分别上传。没有电子原件时，可用“手动添加”录入。

上传后使用当前配置的 AI 服务识别名称、奖项、级别、颁发单位、日期、获奖人、编号和说明。可在“证书识别”单独指定文字模型；留空继承全局配置。证书先在本机提取文字，脱敏后交给 CLI 整理字段，原图不外发，结果需人工核对。

识别完成后打开“核对信息”，对照左侧原件修改右侧字段，点击右上角“确认并保存”；右上角 × 关闭窗口。无法确定的信息保持空白，失败或取消后原件仍保留，可以手动填写或重新识别。重新识别不会直接覆盖已经人工确认的字段，需要在核对窗口选择采用；填入表单后提示立即收起，确认保存后不再显示历史识别提示。

按分类、核对状态和关键词管理荣誉，支持按日期、名称或最近更新排序。已核对条目可单独或批量加入当前简历的荣誉栏目，也可以指定其他文本栏目；同一荣誉不会重复加入。加入后进入简历草稿，请到个人信息或栏目编排调整并保存方案。已加入简历的荣誉与库中同一条资料保持关联：核对保存后，已有简历和当前草稿自动同步全部字段，无需删除后重加。各份简历独立保留显隐、排序和自定义备注；删除库条目时，已有简历保留删除前最后核对的内容。历史导出文件保持原样。原件和分页预览随 ZIP 备份恢复。

荣誉卡片加入当前简历后，按钮变为“从简历中移除”；点击后仅移除当前简历草稿中的条目，库中资料和证书原件、其他简历保持不变，按钮恢复为“加入简历”，可以再次加入。

个人信息中的荣誉条目直接以荣誉名称作为卡片标题，与荣誉库共用简洁的字段名称：荣誉名称、奖项、荣誉级别、颁发单位、获得日期、获奖人、证书编号、分类和荣誉说明。加入简历时完整复制各字段，奖项不再自动拼进名称，级别不再混进说明。荣誉栏目顶部的“添加证书”进入荣誉证书板块，在库中上传、手动录入或选择已有证书加入简历；“排序”跳转并定位到栏目编排中的当前栏目，个人信息中不再逐条显示荣誉排序箭头。

新荣誉条目默认只显示证书名称和获得日期，预览与导出一致；个人信息页将其余资料收在“其他荣誉信息”中。关联荣誉只需点击条目顶部“编辑”，即可在同一窗口修改荣誉内容、逐项显隐、整条显隐与自定义信息，在“其他荣誉信息”区域点击“添加信息”补充自定义资料，点击“确认并保存”统一保存。内容同步到荣誉库及其他关联简历，显隐与自定义信息仅属于当前简历；取消可放弃本次未保存修改。手工添加且未关联荣誉库的条目仍在当前简历内编辑。展开或收起表单不会改变排版显隐。已有的关联条目自动补齐库中的完整资料，并保留显示选择。简历条目编辑弹窗不再重复显示识别结果提示，需要采用重新识别的结果时可进入荣誉库核对。保存本条不会提交或丢弃其他个人信息草稿。

### 项目经历与简历

1. **导入项目**：设置中扫描项目集合并确认归组。一个项目可以关联多个仓库；目录搬家后可在“项目来源与本人贡献”中重新绑定。
2. **分析项目**：点击“分析项目”。CLI 通过只读工具按需列出、搜索和读取关联目录的脱敏源码，分页可继续，生成经历建议和待确认问题。默认精选 3–4 条亮点，标题简短且聚焦一个核心，避免“XX与XX”式拼接；正文一条一句，分句用中文逗号、不用分号，保留格式支持、处理策略、关键技术和结果边界等有效细节，优先压缩重复和套话。通常 80–140 字作为参考，不为字数删掉关键事实。具体技术栈、格式名称及常用缩写可保留，有清晰中文表达的机制和设计模式须汉化，例如 Outbox 写“事务消息表”、Saga 按实际机制写“分步执行和失败补偿”。有可靠数据时优先体现数字，缺少依据时不编造效果。“让 AI 修改”沿用相同写作规则。角色、日期、个人贡献及未核实的量化成果由本人补充确认。
3. **独立会话**：左侧按项目排列会话，点击项目名称右侧的“＋”为该项目新建会话并进入；支持直接切换、改名和归档，设置中可恢复归档会话。每条会话有独立历史、输入草稿和 Codex 会话 ID。
4. **编辑经历**：采用 AI 建议、修改文字、新增、删除、基本信息排序和亮点内部排序都先进入自动保存的草稿。基本信息点击“编辑”后可修改字段；“添加条目”可新增自定义名称和内容。基本信息和项目亮点的眼睛按钮无需进入编辑即可切换显示，隐藏保留原文，只影响当前简历，并随“保存组合”保存，不要求提交项目新版本。预览和 Word 只输出可见内容；其他简历与项目历史版本不受影响。单条亮点或基本信息中的“完成编辑”只保留草稿，不生成版本。确认本次全部修改后，点击“提交为新版本”，一次生成一个正式经历版本。
5. **组合简历**：勾选项目和亮点，调整项目顺序。右侧简历预览自动跟随编辑区的文字、亮点顺序和勾选状态，草稿无需提交即可预览。确认后点击“提交为新版本”，再点击“用于当前简历”更新固定引用，即可保存组合和导出。保存经历不会修改其他简历中已经固定的旧版本。
6. **导出 Word**：点击顶部“导出与模板”打开简历库，在当前方案中选择排版、保存组合或直接导出。导出会先保存方案，再生成独立文件；下方“导出记录”显示首页、实际页数、导出时间，以及 Word、可用的 PDF 和版本清单下载。右侧工作台专用于实时预览。

“简历预览”按照当前内置版式或 Word 模板显示完整排版，取消勾选再勾选仍按编辑区顺序排列。正在编辑的内容与简历固定引用不一致时，会显示实时预览提示，并暂时禁用保存组合和导出，避免生成的文件与预览不同；提交修改并“用于当前简历”后即可继续。预览在输入停顿后自动更新；历史文件统一收在简历库的“导出记录”中，与当前内容一致的文件会标记说明；修改后仍保留导出时的内容，需要重新导出才能生成新成品。下载使用导出时的方案名称，后续改名不会混淆历史文件。

简历库左侧支持搜索、切换和新建简历方案，切换或关闭弹窗会保留本机草稿；每张方案卡片显示保存状态、项目与亮点数量，卡片上的垃圾桶按钮可删除对应方案，确认窗口会显示方案名称。删除其他方案不会切换当前简历；删除正在编辑的方案后切换到其他方案，没有剩余方案时进入空白组合。项目经历、模板和已导出文件保留。导出进行中暂不能删除方案。

多来源项目（例如 TrustGuard）在左侧显示为整体项目和子项目。整体项目保留原有会话，并分析全部关联目录；每个来源目录同时拥有独立的子项目经历、草稿和会话，仅分析自身源码。整体与各子项目可分别勾选加入简历，勾选整体不会自动勾选子项目。点击子项目旁的“＋”可新建独立会话，展开箭头可查看已有会话；工作区上方显示所属整体项目并支持返回。现有多来源项目会在升级时自动补齐子项目，原整体经历、会话和简历引用保持不变。

右上角可选择**浅色、深色、跟随系统**，浏览器会记住偏好。顶部“制作指引”贯穿模板、个人信息、项目、荣誉和编排工作区，按 **模板识别 → 个人信息 → 项目经历 → 荣誉证书 → 组合编排 → 简历导出** 展示整份简历的准备进度。点击大步骤切换工作区，当前步骤下方展示可直接操作的子步骤：个人信息包括基本信息、教育经历、项目经历、荣誉证书和专业技能，其中项目与荣誉分别跳到第 3、4 步；项目经历包括导入项目、智能整理；荣誉证书包括识别荣誉、选择荣誉。教育和技能入口会定位具体栏目，模板入口直接进入识别工作区，组合编排进入栏目排序与显隐设置，简历导出打开简历库。

指引根据实际资料显示就绪状态：空白或隐藏条目不算已填写，隐藏或移除的可选资料栏目无需补齐；荣誉识别完成后还需选择加入当前简历。内置完整简历也算可用模板，无需先调用 AI 识别。未提交项目草稿、引用旧版本、空白经历和导出过期仍会提示；资料就绪后需保存组合，再导出最新内容。简历库左侧的方案卡片显示已选项目与亮点数量，工作台简历预览保持白纸样式。

拖动区域之间带短线的分隔条，可调整项目栏、编辑区和简历区的宽度，以及制作指引的高度；窄屏下支持上下调整编辑区。制作指引向上拖动时先隐藏说明，再隐藏子步骤，最低保留 40 像素高的六步导航（连同拖动条共 48 像素）；向下拉可恢复完整内容，尺寸会自动记忆。AI 会话内的聊天记录与输入区也有分隔条，向上拖动可扩大输入区，记录独立滚动；“本轮讨论范围”位于输入框下方。布局自动记忆，双击分隔条复位，右上角“重置布局”恢复默认大小。分隔条也支持方向键微调（Shift 加速）和 Home/End 调到边界。制作指引可收起；预览工具栏支持适应宽度及 75%–200% 缩放，矢量文字放大仍保持清晰；“放大预览”可独占工作区，按 Esc 或再次点击恢复。

基本信息中的项目标题和参与时间固定在顶部；担任角色、技术栈、项目描述和自定义条目可通过上下箭头或三横杠拖动自由排序。“项目亮点”占位栏用于移动整组亮点，具体亮点仍在下方编辑和编排。基本信息顺序（包括亮点占位栏）进入项目草稿，点击“提交为新版本”保存，再点击“用于当前简历”更新引用；预览和 Word 导出同步采用对应版本的顺序。显隐仍只影响当前简历，不触发项目新版本。已有简历的旧排序会保留，重新排序后由新版本记录。

“未提交的改动”只在当前内容或顺序与正在编辑的正式版本有差异时显示。文字或排序全部改回原样后，自动恢复“内容已提交”，无需再提交新版本；如果其他字段仍有修改，会继续提示待提交。

“未提交的改动”旁提供“撤销改动”。二次确认后，当前项目基线上的基本信息、条目增删、排序和亮点草稿全部恢复到正在编辑的已保存版本；显隐、其他项目和其他版本草稿保留。取消确认不改变草稿；确认期间其他窗口改动草稿时会提示冲突，撤销整体不执行。

项目／会话侧栏提供两种排序：**铃铛**按最近修改排列，计入经历草稿、已保存版本与会话更新；**A–Z**首次点击正序，再次点击倒序。项目和项目内的会话同时排序，默认最近修改，浏览器记住选择。

亮点和“栏目编排”中项目经历栏目内的项目，均可按住上下箭头之间的**三横杠**拖动排序；落点线指示位置，拖到滚动区边缘可继续滚动。松手应用到草稿，Esc 或拖出列表取消；也可聚焦手柄后按空格、上下方向键、空格完成排序。亮点排序和箭头操作均自动保留为草稿，右侧立即同步顺序；多次调整后点击“提交为新版本”统一提交，再点击“用于当前简历”更新固定引用。项目排序保留原引用与亮点选择，浏览器自动记住当前组合，点击“保存组合”正式保存。

## 经历历史与分支

经历编辑区的“当前分支”可切换不同岗位版本；旁边的“历史树”显示全部版本的父子连线、所属分支、保存时间及最新指针。点击节点可预览已保存的内容和相对父版本的变更，点击“查看此版本”载入编辑区。“查看此版本”和“创建分支”位于右侧详情顶部，滚动内容时仍可直接操作；创建分支的表单在按钮下方展开。

有实际修改的工作副本会在基线版本上方显示**“未提交的改动”**，以虚线和空心节点连接，不占用正式版本号。可查看修改后的内容与变更摘要，点击“继续编辑”恢复工作。文字和排序先保留到本机并同步到数据库草稿，关闭页面或重启后可继续；提交成功后草稿节点消失，只增加一个正式版本。不同分支的未提交改动分别显示，不会混入其他分支或已固定的简历内容。

点击“＋”或历史节点下的“从此版本创建分支”，填写如“后端岗位版”“AI 岗位版”的名称即可。新分支会创建独立的起点版本；可选择复制该节点未保存的草稿，复制后仍需保存才会成为正式经历，原分支的草稿保留。各分支独立保存；查看旧版本时，可创建分支继续修改，或“恢复为新版本”在其所属分支追加一次恢复，历史不会被重写。

每个整体项目和子项目各有自己的分支。采用 AI 建议会检查生成时所在分支是否有后续修改；其他分支的发布不会使建议失效。勾选当前项目或点击“用于当前简历”引用当前查看的版本，已有简历引用不会随分支切换自动变化。现有历史升级后归入 `main`，原修订 ID、草稿和简历引用保持不变。

经历分支采用 Git 风格的交互，数据仍统一保存到 SQLite 并随完整备份一起导出，不需要额外初始化 Git 仓库。

## Codex 与 CCSwitch

AI 功能使用原生 Codex CLI，复用文件登录或 Responses 供应商配置，不限定具体版本号；不兼容的必需参数或配置会返回具体错误。无需 WSL；模型只能通过专用只读工具访问脱敏副本。“测试实际连接”会调用所选供应商，模型和 Profile 留空时沿用 CLI 配置。

每轮采用 `codex exec --sandbox read-only --json --output-schema ...`，续聊使用明确的会话 ID。任务全局排队，同一会话只允许一个未完成任务；支持取消、超时、失败重试、重启后中断标记，以及从已保存历史重建模型上下文。

右上角设置的“Codex 与数据”中，可填写全局默认模型并选择思考强度，也可为下列 AI 功能分别设置：

| 功能 | 对应操作 |
| --- | --- |
| 项目分析 | 分析项目、重新分析源码 |
| 普通对话 | AI 会话中讨论整个项目 |
| 亮点修改 | 让 AI 修改、针对单条亮点对话 |
| 模板识别 | Word 模板的 AI 识别及自动修正 |
| 模板完善 | AI 继续完善、按说明调整及后续自动修正 |
| 连接测试 | 测试实际连接 |

模型填写当前 Provider 支持的模型 ID。每项的模型与强度可分别留空，留空继承全局默认；全局留空时继承 Codex CLI / Profile 配置。强度支持最低 `minimal`、低 `low`、中 `medium`、高 `high`、最高 `xhigh`，须由所选模型支持。点击“保存设置”后用于新提交任务，包括已有会话的下一次发送；已排队或运行中的任务保持提交时设置。模板的每一轮自动修正使用同一组设置，更换模板模型或强度后下次识别会重新调用 AI。“测试实际连接”会先保存设置，再使用连接测试项发起真实请求。

当前已实现完整 Codex Provider；API Provider 保留统一接口，后续接入自己的 Agent。`Provider.run()` 返回统一的结构化建议，不直接修改经历或简历。

## 个人信息与栏目编排

顶部提供“项目经历 / 个人信息 / 栏目编排 / Word 模板”四个功能区，使用同一份当前简历资料。前三个功能区共用右侧简历方案，Word 模板使用完整工作区。项目经历仍在原工作台中编辑、讨论和管理版本。没有导入项目时，也可以先填写个人资料。

基本信息中点击“编辑”修改资料和照片，点击旁边的“保存”直接保存基本信息，成功后回到只读状态。其他栏目的待保存修改仍保留为草稿；右侧“保存组合”可统一保存整份方案，并结束基本信息的编辑。未保存的基本信息草稿自动进入编辑状态；已保存资料（包括空白资料）需点击“编辑”修改，保存失败时保留输入供重试。

每条教育经历和其他栏目资料也有独立的“编辑 / 保存”：保存只提交本条内容，不提交其他条目或基本信息的草稿；新栏目会一并建立必要的父级结构。保存成功后，该条输入和显隐按钮切回只读；失败时保持可编辑，右侧“保存组合”也会结束已保存条目的编辑。

“个人信息”支持姓名、求职意向、性别、年龄、电话、邮箱、专业成绩、所在地、个人主页和照片。照片仅在本机保存，上传 PNG/JPG 后自动居中裁剪为 3:4。基本信息固定放在简历顶部；空字段不占位置。教育背景支持多条学校、专业、学历与在校时间，其余栏目可填写标题、补充信息、日期和多行正文，也可以只填写正文。

每项资料后的小眼睛可切换其在简历中的显示；基本信息和已保存条目须先点击各自的“编辑”。各栏目还可通过条目右侧的小眼睛隐藏整条资料；关联荣誉在统一编辑窗口中操作。闭眼表示隐藏，原文字和照片仍保留，再次点击即可恢复；预览和 Word 导出同步省略隐藏内容，显隐设置随方案保存。文本条目标题与所属栏目同名时，排版只显示一次栏目标题，提升为大栏目后也一样。

基本信息旁的“添加信息”可增加自定义名称和内容；每条教育经历或其他资料右侧的“添加条目”可为这条资料增加信息项，例如籍贯、毕业时间、研究方向。自定义项支持改名、隐藏和删除，每处最多 20 项，名称或内容为空时不进入预览和 Word。栏目顶部的“添加教育经历 / 添加条目”用于新增一整条经历。栏目字段与基本信息一样采用紧凑同行布局。

“栏目编排”默认包含教育背景、项目经历、荣誉证书与专业技能四个大栏目，主修课程默认归入教育背景。每个大栏目右侧的“添加子栏目”会直接新增下一级栏目并选中名称，项目经历也支持添加子栏目；整体保持大栏目和子栏目两级。可自定义新栏目、重命名、隐藏、拖动或点击上下箭头调整同级顺序；大栏目移动时带上所属子栏目。通过“所属层级”可把课程提升为大栏目，或把通用栏目归入其他大栏目。当前支持大栏目、子栏目、资料条目的结构；含子栏目的大栏目须先移出子栏目才能降级，项目经历保持独立大栏目。

隐藏大栏目会一并隐藏其子栏目，资料仍保留；删除大栏目会把其子栏目提升到顶层，可点击撤销恢复被删除的栏目正文。项目经历可隐藏，不能在栏目编排中删除。空白栏目不会在成品中留下标题。

栏目编排中的荣誉条目依次提供铅笔、上移、拖动手柄、下移和 ×。点击铅笔弹出荣誉编辑窗口；关联荣誉的内容同步至库，手动条目或来源已删除的条目只修改当前简历。点击右侧 × 将条目从当前简历草稿移除，荣誉库卡片同步恢复为“加入简历”。

荣誉、教育经历及其他资料条目也会列在各自栏目内，使用与项目经历相同的上下箭头和三横杠手柄排序；支持拖动、键盘排序和 Esc 取消。大栏目与子栏目各自维护内部条目顺序，隐藏条目仍可排序。调整后“个人信息”和预览立即使用同一顺序；教育等其他条目仍可在个人信息中上下移动并同步回来，荣誉统一通过栏目顶部“排序”进入编排页操作。点击“保存组合”保存本份简历的顺序，荣誉库及其他简历不受影响。

这些修改会实时反映到右侧预览，并暂存为当前方案的浏览器草稿。点击“保存组合”后，资料、照片、层级、顺序与显隐一同保存到本机数据库并纳入 ZIP 备份，各方案互不影响。只改资料或栏目后，之前的导出会标记为旧内容，需重新导出。

新方案默认使用“内置 · 完整简历”，无需导入模板即可导出蓝色抬头、教育背景与项目经历等栏目。使用 AI 适配的完整模板时，编辑个人资料和栏目会继续沿用该模板。右侧统一的“简历预览”显示当前版式的真实 Word 排版，未保存的资料修改也会自动更新；在“栏目编排”的项目经历栏目内可排序、移除项目或返回项目编辑区。预览完成后直接显示简历页面，仅更新中或失败时显示简短提示。

## 选择本机文件和文件夹

所有本机路径输入框均保留手动填写，并提供 Windows 原生选择按钮：模板导入可选择 Word、PDF 或图片文件，项目集合及来源路径选择文件夹，Codex 可执行文件选择本机启动程序。照片输入本身也可直接打开系统文件选择窗口。

“来源目录 / 来源路径（每行一个）”旁的“添加文件夹”会追加所选目录并避免重复，支持连续添加多个来源。选择窗口从已填路径所在目录打开；点击取消保留原输入。选择文件仅回填完整路径，读取模板、扫描目录和保存来源仍由各自操作按钮执行。

## Word 模板

“当前简历”的**导出排版**和 Word 工作区的**模板库**都会打开同一个大尺寸二级弹窗。左侧可查看全部模板、我的喜欢和分类，内置及新导入模板默认归入“未分类”。支持新建分类，选中模板后在右侧调整所属分类；删除分类会将模板归回未分类，并保留收藏。点击右侧名称旁的铅笔可重命名导入模板，按 Enter 或勾号保存，按 Escape 取消；已使用模板也可改名，不影响简历引用。内置模板名称固定，回收站模板需先恢复。

选中导入模板后，点击列表上方的**删除模板**，核对名称后移入项目内的**回收站**。内置默认模板、被任何简历方案引用的模板不能删除；需先给相关方案更换模板。回收站内可恢复原分类与收藏，也可确认后**永久删除**。移入满 30 天后自动清理：程序运行时每分钟检查，未运行时在下次启动清理。永久删除会清除模板文件、保存的映射与识别记录，以及不再被其他模板使用的缓存和试填文件；不能撤销。

右上角可搜索名称、切换列表/卡片展示或按名称/最近保存排序。卡片和详情显示 Word 真实首页预览，内置版式使用示例内容；首次生成需要本机 Word，后续复用缓存，失败时可重试。点击爱心添加或取消 **Like**，分类及收藏保存在本机数据库中，两个入口共用，重启或备份恢复后保留。单击模板只改变弹窗内选择，点击“选择模板”或双击才确认；取消或按 Escape 返回原工作区并保留原模板选择。

点击顶部“栏目编排”右边的 **Word 模板**，可在“模板库”中查看内置版式和已导入模板；其他板块的“管理模板”也会跳转到这里。“内置 · 完整简历”自动展示当前资料的真实 Word 预览，点击“用于当前简历”即可应用，内容仍在个人信息和栏目编排中编辑。也可导入文档进行 AI 完整简历识别：

1. 先填写当前简历资料并选定项目经历，选择 Word（`.docx`、`.doc`、`.docm`、`.rtf`）、PDF 或图片（PNG、JPEG）后点击“AI 识别”。程序先自动整理格式，再使用设置中的 AI 识别，可随时取消。原件先本地解析或 OCR，模型查看脱敏文字、位置和带节点编号的马赛克图片；原图留在本机，仍无法辨认的照片及装饰需人工核对。
2. 程序会检查模型建议，并自动把遗漏、范围错误和当前资料缺少的位置反馈给 AI 修正，最多三轮。固定字段标签会自动补齐，单处错误不会把后面的已识别内容全部算成待处理。
3. 默认查看“识别摘要”；自动检查通过后会用当前资料生成 Word 试填。右侧“AI 助手”支持直接说明调整要求，或点击“AI 继续完善”。失败或退步时保留已有最佳建议，仍有疑问会集中显示。
4. 需要自己调整时，点击摘要中的资料或栏目，或进入“Word 试填与调整”。左侧保留 Word 真实分页，右侧按资料和栏目选择要修正的内容；原文列表、空白位置、照片用途及同级范围选择收在高级选项中。修改后自动校验，旧页面会标明待更新；点击“更新试填预览”核对最新效果后再保存或下载。
5. 检查试填中的内容和分页，点击“保存识别结果”，将模板独立保存到模板库。需要切换当前简历时，再点击“用于当前简历”；保存本身不改变简历的模板选择。修改映射后须先保存新版本再应用。项目内容来自选定的固定版本和亮点，试填不会提交项目草稿。

支持正文、表格单元格、Word 文本框、页眉页脚、脚注和尾注中的可编辑文字，以及内嵌照片；重复范围可以是一组同级段落、完整表格或表格行。保留模板字体、段落样式、表格和页面设置。原文件不修改；已替换且不再使用的旧照片和链接资源从导出包中清理。

超链接、合并字段及其他动态域会在模板副本中自动转为普通文字，保留已有显示内容和样式；没有显示内容的域整理为空白位置供填写。页码与总页数保留。修订自动接受当前版本，批注、内容绑定、编辑锁定和失效脚注引用自动整理。新文件识别失败时，提示会注明文件名；下方仍可查看已有模板，其检查状态只对应当前显示的结果。

AI 不能保证所有陌生文档一次识别正确。编辑批注会在副本中自动忽略，脚注和尾注参与识别，连续分节设置会保留；依赖分栏或浮动文本框的复杂重复栏目会继承原字体并整理为纵向条目，支持多条经历自然换行，调整会在试填前说明。旧版 Word 自动转换为 DOCX，可编辑 Word 沿用原生结构识别。PDF 单独按页处理：可靠的原生文字层先在本地恢复段落、同行资料、表格与分栏，图标、照片、线条和栏目底色从视觉层独立提取；局部装饰不含旧正文，并跟随对应段落移动，大面积页面底色固定在页面后方。字体编码的小图标保留为局部图片，重复列表符号恢复为可编辑文字。扫描页、隐藏 OCR 层、乱码或版面转换失败的页面先本地 OCR、遮盖敏感文字并打码图像，再把脱敏整页交给 AI 恢复文字、照片和版式，原文和照片在本机放回 Word；混合文档逐页选择处理方式并保留各页尺寸。真正空白的 PDF 页在本机保留；扫描页 OCR 没有识别到文字时会停止并说明原因。具体处理和辨认疑问显示在识别摘要中。恢复某页失败时自动重试一次；空白来源按当前资料字段建立占位框架。完全损坏或加密且无法读取的文件会说明实际失败原因。固定大小文本框和固定行高可能容纳不下更长的资料，应根据真实预览调整原模板后重新分析。栏目按名称匹配；新增大栏目会沿用已识别的大标题样式，普通条目和个人基本信息的新增字段会在生成时自动补行；新增子栏目或没有可复用样本时仍需补充映射。已识别的栏目标题、条目和样式会按照“栏目编排”整体排序，子栏目跟随父栏目；空栏目与隐藏栏目不留下孤立标题和空标签，GPA 等已填写信息仍会保留。栏目标题可映射到对应栏目名称；浮动标题会转换成嵌入图形以避免覆盖正文。识别后会先实际试填；栏目跨容器、跨分页分节或共用不可移动区域时，自动重建为独立段落并重新识别。

分析发送脱敏的模板文字、结构、位置和字段需求；不发送原图、照片和个人资料原值。切换顶部功能区会保留人工映射、选区和模板名称；资料改变后需要重新试填。分析任务属于本次应用运行，刷新页面会恢复原始分析结果，未保存的人工调整不跨页面刷新保留；重启应用需重新分析未保存模板。保存后的模板、原文件和映射进入本机数据库与常规备份。

PDF 模板的顶部资料会在试填时按实际内容重新安排：姓名标题保留源对齐意图，联系方式和新增信息放不下时整项换行，照片独立留位，图标随对应字段一起显示或隐藏。栏目标题底块会随长标题扩展并为正文留出空间。普通 Word 模板继续沿用原布局规则。若旧 PDF 模板仍保留完整图标和可确认的字段关联，可复用映射更新试填；若提示缺少来源位置证据，请从源 PDF 重新识别。

图片和扫描件由轻量本地 OCR 预处理，难页最多提高分辨率复核一次。看不清或漏字时请核对原件并手工修正，原始像素不会发给模型。

已保存的模板保留原有快照和映射，不自动覆盖。若 PDF 模板是在旧版中导入、已经丢失图标或布局，请重新选择源 PDF 启动一次新的识别，核对试填结果后另存；直接重开旧模板不会重新转换源 PDF。

从模板库选中已保存模板后，会自动打开识别结果，不再调用 AI。在“Word 试填与调整”页右侧直接修正内容，修改后保存为新版本，旧模板及已保存简历的引用保持不变。底部统一提供“用于当前简历”，可采用已保存且未修改的版本；当前已使用时显示“当前已使用”，无需重复应用。只保存后刷新页面仍会重开该模板，不会自动切换当前简历。加载失败时可点击“重新加载模板”重试。

使用模板后新增个人主页等基本信息或自定义信息时，预览与导出会在个人资料区自动补充填写行，沿用附近联系方式的字体、缩进和行距，无需重新识别。隐藏或清空的新增信息不占行；生成时只调整本次输出，不改写模板库中的原文件和映射。

新增“实习经历”等大栏目时，会复制已识别大标题的完整样式，包括图形、底纹和字体，并按“栏目编排”的顺序放置。普通条目新增标题、补充信息、时间、详细内容或自定义信息时会自动补充填写位置；空的新增字段不占行。隐藏或清空栏目后，标题和内容一起收起，恢复显示时仍沿用原样式。这些调整由预览与导出自动完成，无需重新识别；模板中没有可复用的大标题样本时，仍需先补充标题映射。

隐藏基本信息会连同标签一起移除。联系方式按原列向上补齐，例如隐藏左列邮箱后，下方的个人主页上移到邮箱位置，右列电话和所在地保持对齐；单列资料和普通表格中的空行也会收起。

大栏目默认接在前一个栏目之后连续排版，已有栏目和新增栏目均不沿用原模板中的强制分页、段前分页或另起页分节。标题装饰与原有分栏保持一致，只有当前页空间不足时才自然换页；标题仍尽量与首条内容保持同页。

重复条目的标题和元信息会参照同一列正文的有效缩进对齐，新增字段共用同一文字起点，不继承多余的列表编号。隐藏字段时，其独占的标签、圆点或编号段落及空表格行会一起收起；同段其他文字和装饰图片会保留。多栏、独立单元格、固定定位和右对齐日期仍沿用原布局。

模板库只提供已确认完整映射的模板。当前方案引用的模板不可用时，请重新选择完整模板，或导入原 Word 文档进行 AI 识别；原文件和历史导出不会被删除。

精确页数与 PDF/图片预览使用 Windows 上的 Microsoft Word。Word 不可用或渲染失败时仍可下载 DOCX，界面会明确显示原因，不估算页数。LibreOffice 与 Word 对浮动文本框的排版可能不同，当前模板以 Microsoft Word 结果为准。

## 数据和恢复

SQLite 是主数据来源。数据目录包含经历修订、草稿、会话、任务、模板、引用证据副本、历史快照和导出记录，均不纳入源代码 Git。

在“Codex 与数据”中下载完整 ZIP 备份。关闭应用后恢复：

```powershell
uv run python -m resume_maker.cli --restore "D:\Backups\resume-maker-backup.zip"

# 恢复到另一个独立目录
uv run python -m resume_maker.cli --data-dir "D:\ResumeMakerData" --restore "D:\Backups\backup.zip"
```

恢复前校验 ZIP 路径、数据库和必要资源，拒绝覆盖正在使用的数据目录；原数据保留在同级 `*-before-restore-*` 目录。恢复后使用保存的聊天历史重建 Codex 上下文，不依赖另一台电脑的 CLI 会话文件。项目源码本身不在备份内，搬迁后应重新绑定路径。

项目分析和对话按需读取当前关联目录，模型只收到脱敏路径及文字。文件列表、搜索及长行均可分页继续，不设整库文件数、总量、单文件大小或遍历总数预算。凭据、二进制、链接、依赖及应用自身数据目录仍排除，普通源码 data 目录和文本锁文件可读。超大文件的处理仍受机器资源和任务超时影响。返回引用在本地还原后核对行号和原文，历史证据继续保留。

## 隐私保护

在工作台设置中补充准确敏感词，使用“本地检测一段文字”验证常见格式；“最近脱敏材料包”显示最多 10 份交给 CLI 的材料，不是完整 HTTP 抓包并支持清除。自动规则可能遗漏未知姓名和间接身份线索。真实资料和备份仍保存在本机，详细范围及连接要求见 [隐私保护](privacy.md)。
