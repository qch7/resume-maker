# 初步版本开发记录

## 确认的范围

- 本机 Web，Python/FastAPI、React/TypeScript、SQLite。
- 项目分组的会话侧边栏，同一项目可新建多个独立会话。
- 本机 Codex 优先，Provider 接口允许后续增加 API Agent。
- 不可变经历版本、逐条人工编辑保存、可恢复草稿、AI 建议采用和冲突检查。
- 固定版本的简历组合、当前 Word 模板适配、可编辑 Word 导出。
- 保留模板其他栏目，只替换项目经历；允许多页并报告渲染页数。
- 源代码和个人数据分离，逐步开发、验证并提交 Git。

## 开发顺序

- [ ] 1. 仓库、运行环境、数据模型与迁移。
- [ ] 2. 项目扫描、输入快照、经历修订、草稿、组合。
- [ ] 3. Codex Provider、持久化会话、队列、取消与错误恢复。
- [ ] 4. Word 模板适配、导出和真实渲染验证。
- [ ] 5. React 工作台、会话侧栏、逐条编辑、设置和导出。
- [ ] 6. 集成验证、启动入口、文档和最终提交。
